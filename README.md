# Inventory Management Dashboard

## Project Overview
This project contains an Inventory Management Dashboard created using Microsoft Power BI.

The project file is provided in `.pbix` format and can be opened using Power BI Desktop.

## Tools Used
- Microsoft Power BI
- Power BI Desktop

## Project File
- `Inventory_Management_Dashboard.pbix`

## How to Open
1. Download the `.pbix` file from this repository.
2. Open Microsoft Power BI Desktop.
3. Open the downloaded file to view the dashboard.

## Project Purpose
The purpose of this project is to present inventory-related information through a Power BI dashboard.
